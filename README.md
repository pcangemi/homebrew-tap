# Homebrew tap

Formulae for tools published by this account.

```sh
brew install pcangemi/tap/ccorbit
```

| Formula | What it is |
|---|---|
| [ccorbit](https://github.com/pcangemi/ccorbit) | A live, read-only terminal view of every Claude Code session: wall, 3D hologram HUD, director mode, code city |

The formulae are generated by each project's release builds.
